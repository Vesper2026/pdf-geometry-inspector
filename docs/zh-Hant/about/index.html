關於唯讀 PDF 幾何檢查，以及如何在編輯前使用。

關於頁面檢查工具

PDF Geometry Inspector 是 Vesper2026 提供的 MIT 授權 Python 工具，唯讀取得頁面框、旋轉、UserUnit 與檔案中繼資料。

編輯之前先檢查

KomoPDF 提供 PDF 編輯工具。先用檢查工具定位頁面、了解尺寸，再決定是否需要調整。

唯讀處理

CLI 在本機使用 pypdf 輸出報告，不上傳文件。中繼資料可能缺失或不正確；幾何檢查不驗證簽章、不認證文件真偽，也不執行安全遮蔽。
