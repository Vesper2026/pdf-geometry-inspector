維護關係

PDF 頁面檢視桌的維護關係，以及本機唯讀檢查的限制。

相關產品生態的維護工具

Vesper2026 維護這個 MIT 授權工具與網站，與相關的 Eqvero、KolmoPDF、KomoPDF 生態屬同一維護團隊。我們公開說明此關係，不偽裝為獨立產品評測。

CLI 在你自己的 Python 環境使用 pypdf，讀取本機檔案並輸出報告，不上傳 PDF。這個靜態網站沒有上傳表單、分析追蹤或帳號；安裝依賴會連接套件來源，目前網站由 Vercel 託管，GitHub 保留原始碼與 Pages 副本。

檢查與編輯是兩件事

KomoPDF 是相關的 PDF 編輯產品。本工具只協助在編輯前找出幾何問題，不實作編輯器、不更改頁面，也不保證任何編輯操作能保留簽章效力。

中繼資料來自檔案本身，可能缺失或不正確。正常的作者欄位與沒有提示的幾何報告，都不能證明來源、機密性或文件真偽。
