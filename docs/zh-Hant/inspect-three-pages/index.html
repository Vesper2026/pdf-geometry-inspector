01 / 可重現教學

同樣是 A4，PDF 的可見尺寸為何不同？

檢查三頁合成 PDF，分清頁面框、裁切與旋轉，再決定是否需要編輯。

同一份檔案可以混合直向 A4、旋轉 A4 與裁切後的 Letter，這不必然表示損壞。真正需要了解的是每頁的頁面框與旋轉值。練習使用空白合成頁，不需要客戶文件。

1. 建立隔離環境

準備 Python 3.10 或更新版本，在儲存庫根目錄建立專案環境並安裝固定版本依賴。

python -m venv .venv
# Windows PowerShell
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe examples/generate_sample.py
.venv/Scripts/python.exe pdf_geometry.py examples/sample.pdf --output examples/output

macOS 或 Linux 將 .venv/Scripts/python.exe 換成 .venv/bin/python。可直接下載產生的範例 PDF，對照 JSON 報告與文字報告。

2. 比較實際可見範圍

第 1 頁是 A4 MediaBox；第 2 頁使用相同的未旋轉頁面框，但頁面旋轉為 90 度，所以顯示寬高互換。第 3 頁是 Letter MediaBox，配上較小的 CropBox。若裁切座標為 [18,36,594,756]，寬度是 594−18=576，高度是 756−36=720。UserUnit 為 1 時，可見尺寸為 203.2 × 254 毫米。

3. 檢查不等於編輯

CLI 只輸出報告，不改寫 PDF。根據頁碼與頁面框決定是否需要處理；混合尺寸本身並非錯誤。需要編輯時，可使用相關的 KomoPDF，但本報告不代表編輯器可以自動修復所有特殊檔案。

範例只有空白頁面與中繼資料，沒有實際正文。工具不能判斷閱讀順序、文字可編輯性、OCR 品質、印刷出血是否合適，或數位簽章是否有效。
