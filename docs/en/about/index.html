About & affiliation

The PDF Geometry Desk maintenance relationship and the limits of its local page inspection.

Maintained in the related-product ecosystem

Vesper2026 maintains this MIT-licensed utility and site within the same maintenance team as the related Eqvero, KolmoPDF and KomoPDF ecosystem. We disclose that connection rather than present this as an independent product review.

The CLI uses pypdf in your own Python environment. It reads local files, writes reports and does not upload PDFs. The static website has no upload form, analytics or accounts. Dependency installation contacts the package index; GitHub hosts the pages.

Inspection and editing are different jobs

KomoPDF is the related PDF editing product. This utility helps identify geometry questions before editing; it does not implement the editor, modify pages or guarantee that any particular editing operation preserves signatures.

Metadata strings come from the file itself and can be absent or incorrect. Neither an ordinary author field nor a clean geometry report proves provenance, confidentiality or document authenticity.
