About

About read-only PDF geometry inspection and how to use it before editing.

About the inspector

PDF Geometry Inspector is an MIT-licensed Python tool by Vesper2026. It reads page boxes, rotation, UserUnit and file metadata without rewriting the PDF.

Inspect before editing

KomoPDF provides PDF editing tools. Use the inspector first to locate a page and understand its dimensions, then decide whether an edit is appropriate.

Read-only inspection

The CLI uses pypdf locally and writes reports without uploading documents. Metadata can be absent or incorrect; geometry findings do not validate signatures, authenticate a document or perform secure redaction.
